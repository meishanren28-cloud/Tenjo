# 强势回踩资金友好大师（72只）V4

这是一个 Streamlit 日股筛选网站。目标不是假装预测明天一定涨，而是：**先排雷 → 判断趋势背景 → 判断回踩质量 → 等重新转强 → 最后在质量相近的候选里优先资金占用更低的股票。**

## V4 新增：更科学的评分结构
- **背景分**：20/60日动量 + MA20斜率 + 过去20日站上MA20的比例 + 分段高低点结构。避免一次暴拉就被误判成长期强势。
- **触发分**：突破前一日高点、连续回升、上涨伴随合理放量。背景强但没有触发，会显示“好候选，等转强”。
- **回踩质量**：靠近支撑、未破MA20/近期平台、从高点适度回撤；下跌时缩量比放量杀跌更健康。
- **波动风险**：增加 ATR14、长上影/冲高回落风险。
- **流动性风险**：20日日均成交额过低会扣分。
- **akippa式弱票硬惩罚**：刷新20日低点、低点持续下移、5/20日走弱、放量不涨。跌得多不构成买点。
- **追高惩罚**：单日突然大涨且明显远离MA5时扣分；强趋势突破仍可参与，但要等承接确认。

## V4 新增：资金友好度
- 日本现物通常按100股一手估算，因此网站直接显示：`一手资金 = 当前价 × 100`。
- 页面可以设置“单只股票最多愿意占用的一手资金预算”。
- 资金友好度最多只加10分，只对 A/B 档健康候选生效。
- **便宜不能救弱票**：连续创新低、破位、放量不涨的低价股不会因为便宜被抬进推荐区。
- 同样质量时，所需资金更少的股票优先，符合小资金账户的现实约束。

## 评级含义
- **A｜强背景+已触发**：趋势背景和买点触发同时较好，仍需看实际盘口。
- **B+｜好候选，等转强**：背景不错、位置也可以，但尚未出现足够明确的重新转强信号。
- **B｜观察**：结构尚可，但优势没有那么明显。
- **C｜中性**：没有明显硬伤，也没有明显优势。
- **回避**：出现破位、持续创新低等硬伤。

## 日股涨跌停
网站按 JPX 正常制限值幅表，用前一交易日基准价估算正常涨停价/跌停价。特殊情况下（例如连续无成交封板后）制限值幅可能临时扩大，应以 JPX 当日公告为准。

## 数据
- 行情：Yahoo Finance / yfinance（免费，可能延迟，不是东证官方逐笔实时）
- 新闻：Google News RSS（免费）
- 股票池：固定72只，保存代码、日文名、中文译名；行情只按代码（例如 `6203.T`）抓取。
