# 强势回踩资金友好大师（72只）V8

这是一个 Streamlit 日股筛选网站。目标不是假装能预测明天，而是：**先排雷 → 判断趋势背景 → 判断回踩质量 → 等重新转强 → 看涨幅能不能留住 → 再结合资金占用和不同交易时段做排序。**

## V8：四种分析模式

### 1. 开盘前
偏重昨收结构、趋势背景、回踩位置与隔夜新闻。今天还没开盘，所以不会把“盘中转强”当作已经发生。

### 2. 盘中
额外抓取免费 5 分钟级别行情，重点看实时转强、当日位置、距日高、量价、冲高回落和追高风险。

### 3. 收盘前｜大引不成
这是专门给“先挂低价限价，若没成交则收盘集合竞价转成市价”的隔夜策略。

重点看：
- 原本趋势背景不能差；
- 尾盘价格最好处在当日相对高位，但不能已经失控加速；
- 最后约30分钟不能明显跳水；
- 最好站在当日 VWAP 上方，但离 VWAP 太远也会扣分；
- 尾盘量能适度增强比突然爆量冲顶更好；
- 当天冲高后的涨幅要能留住；
- 日内涨幅过大、尾盘骗炮、冲高全吐、结构弱都会重罚。

网站会给出 **“大引不成资格”**。如果当天没有股票通过硬门槛，会明确显示：**今天不建议为了下单硬买。**

> 东证现货连续交易到 15:25，之后是 5 分钟 pre-closing，15:30 进行收盘集合竞价。JPX 的 Funari（不成）是限价单若未成交，在收盘集合竞价时转为市价单。实际下单规则以你的券商界面为准。

### 4. 收盘后预测明天
偏重收盘质量、全天涨幅保留、量能、关键位是否守住和新闻催化，用于第二天候选排序。

同一只股票在四个模式得分不同属于设计预期。

## 核心规则
- **原本就强 + 回踩不破关键位 + 再次转强，才考虑买。**
- 连续创新低、收盘重心持续下移的弱票重罚；跌很多不自动抄底。
- 放量不等于强：有量不涨、冲高回落、收盘弱都可能是承接不足。
- 类似 akippa 的弱趋势票，即使突然暴拉也不因为“一根大阳线”追。
- 强趋势突破可以参加，但反对失控加速后的情绪追高。
- 资金少是现实约束：质量相近时优先一手资金更低的股票；便宜绝不救弱票。
- 重视涨幅保留率：冲高后能把涨幅留到收盘加分，反复冲高全吐扣分。

## 动态止盈
网站固定显示止盈计划：
- 参考买入价 / 实际成本价
- **第一止盈**
- **强势续抱目标**
- 对应收益率

止盈结合 ATR14、20/60 日前高压力、买入价和通常涨停价计算，不是统一死板 +5%。非 A 级候选也会显示测算，但会明确标注“仅测算”。

## 资金友好度
- 按日本现物常见 100 股一手估算：`一手资金 = 当前价 × 100`。
- 页面可设置能接受的一手资金预算。
- 资金友好度最多加 10 分，而且只对健康候选生效。

## 日股涨跌停
按 JPX 正常制限值幅表，用前一交易日基准价估算通常涨停价/跌停价。连续封板等特殊情形可能扩大制限值幅，应以 JPX 当日公告为准。

## 股票身份
股票池固定 72 只，同时保存：
- 代码
- 日文正式/常用名
- 中文译名

行情抓取只按代码（如 `6203.T`），名称只用于显示和新闻搜索辅助，减少串票风险。

## 数据
- 行情：Yahoo Finance / yfinance（免费，可能延迟，不是东证官方低延迟行情）
- 新闻：Google News RSS（免费）
- 盘中/尾盘：尽量使用 5 分钟级别免费行情，因此收盘前快速变化时必须再看券商盘口。

## 部署
1. 把 `app.py`、`requirements.txt`、`README.md` 上传到 GitHub 仓库根目录。
2. 在 Streamlit Community Cloud 选择该仓库。
3. Main file path 填 `app.py`。

## V12：健康回调与剩余空间
- 新增“回调质量分”：偏爱强趋势中的 -0.8%~-3.5% 温和回踩，而不是奖励单纯下跌。
- 回调必须配合：支撑未破、MA20结构未坏、5日趋势未崩、下跌量能不过度放大。
- 新增“上方空间/支撑风险比”：仅对健康候选估算回到20日高点的空间，相对当前到关键支撑的距离。
- 回调质量在开盘前、盘中、收盘前大引不成、收盘后四种模式中的权重均提高；追高/深跌仍会被扣分。
- 资金友好仍只是合格候选之间的加分项，不会把便宜弱票救成推荐。


## V13：强势突破追强通道
- 默认仍优先健康回调。
- 对真正强势、接近/突破近期高点、冲高后能留住涨幅的股票，允许进入“追强”候选。
- 追强必须先过风险门槛：近期低点持续下移、冲高保留率差、冲高失败次数过多、20日趋势偏弱、弱势惩罚高，都会直接取消资格。
- 单日加速过猛和 ATR 波动过高会额外扣分。
- 目的：允许追真正的主升/价格发现，同时排除 akippa 式弱票突然暴拉诱多。


## V14：一键回测 + 自动相似结构校准
- 一个按钮完成，不需要手动选样本、设权重或准备数据。
- 自动抓取股票池约2年日线，建立历史技术结构样本。
- 每个历史样本只使用当时已经存在的数据，再观察之后1天/3天结果，避免未来数据泄漏。
- 自动融合：
  - 个股自身历史相似形态；
  - 全72只股票池的相似结构。
- 个股自身历史最多占35%；IPO/短历史股票会自动更多依赖相似股票。
- 概率使用小样本收缩，防止少量案例产生虚假的“90%胜率”。
- 输出：次日上涨概率、3日延续概率、3日假突破风险、相似样本数、次日/3日高低点中位数。
- 历史校准只有限度影响总分；如果历史假突破风险显著偏高，会取消“追强资格”，但不会覆盖实时新闻、盘中结构和硬风险规则。
- 目的：尽量把 4073 类真强势突破与 akippa 类弱势反弹区分开，而不是用“涨得多/跌得多”一刀切。

## V18：海外 / 韩股 / 加密 / 宏观催化自动识别
- “全自动分析”新增跨市场催化层，不需要用户自己看美股、韩股或BTC。
- 因子池包括：SOX、Nasdaq100、SMH、NVIDIA、Micron、SK hynix、Samsung、BTC、铜、黄金、原油、USD/JPY、美国10年期收益率、美股金融、美股军工。
- 不使用“科技股固定跟Nasdaq”这种硬编码判断。程序会针对每只日股，计算过去约100个交易日的**海外因子领先关系**：
  - 每个历史日股交易日只匹配此前已经完成的海外交易日；
  - 使用 Spearman 相关并对极端收益做截尾，降低少数异常日的干扰；
  - 样本不足或相关性接近噪音的因子不计分。
- 只取每只股票最有解释力的最多3个因素。
- 当前因子涨跌会按历史相关性、当前波动标准化值、样本可靠度和“新鲜度”动态加减分。
- 新鲜度限制：
  - 美股只有在相对下一次日股开盘出现了**新的已完成美股交易日**时才加分，避免把昨晚已经反映过的美股重复算两次；
  - 韩股主要作为同区域/同产业的低权重“同行广度”；
  - BTC、汇率、商品因交易时段更长，可作为适度的隔夜辅助。
- 海外催化总影响被限制在 ±8 分，不能盖过日股自身趋势、风险、新闻、PTS和历史回测。
- 页面会显示“海外催化分 / 状态 / 主要关联因子”，例如：`PHLX半导体 +1.8% / 相关+0.46 / +2.1分`。


## V19：尽可能最新的免费海外动态
- 海外/韩股/BTC/汇率/商品当前催化，从“最新日线”升级为 **Yahoo/yfinance 最新可用5分钟数据**。
- 使用 `interval="5m"`；美股/ETF请求 `prepost=True`，因此 Yahoo 提供时可纳入盘前/盘后。
- 5分钟海外数据缓存约90秒，避免每次页面重绘都重复请求。
- 历史相关性仍然用日线计算，避免用几根5分钟K线误判长期关系；当前催化用5分钟最新价格。
- 每个催化项显示更新时间与“距现在多少分钟”。
- 新鲜度自动衰减：
  - BTC / 汇率 / 商品等长时段市场：15分钟内权重最高，之后逐级降低；
  - 韩股盘中：越接近当前时刻权重越高；
  - 美股在日本开盘前，即使已收盘数小时仍属于下一次日股开盘的新信息；日本盘中则大幅降权，避免把已经反映在开盘价里的昨晚美股重复计算。
- 如果5分钟行情取不到或过旧，该因子不计分；不会拿旧日线冒充“实时”。
- 海外层仍然只是辅助：开盘前/收盘后最多约±8分，盘中/收盘前最多约±4分，不覆盖日股自身结构、新闻、PTS和回测。


## V19.1：SciPy依赖修复
- 修复海外关联计算导致的 `ModuleNotFoundError: scipy`。
- 不再调用 `pandas.Series.corr(method="spearman")`。
- 改为“先对两组数据取排名，再对排名计算 Pearson 相关”，数学上等价于 Spearman 秩相关。
- 因此无需新增 scipy，Streamlit 部署更轻、更稳定。


## V19.2：提高100股资金适配权重
- 资金友好度由“轻微平手项”提高为“中等权重平手项”。
- 仍然只给 A / B+ / B 等合格候选加分，弱势票不能因为便宜翻身。
- 评分不再按固定绝对价格档位，而是按 `100股所需资金 / 用户设定单票预算` 动态计算。

  - 约23万一手：9分

- 初始72股扫描和新闻候选筛选也使用用户当前预算，不再固定按30万预算预筛。


# V20：实战预测日志 / Top5 / 回踩买点

## 现在怎么验证
每个模式每次点击“全自动分析”都会冻结Top5：
- 预测时间
- 当时价格
- 综合分/结论
- 回踩买入区间
- 当时失效位
- 第一止盈 / 强势目标
- 当时的关键评分指标（保存成JSON）
- 新闻 / 海外催化 / 历史校准状态

因此第二天不能改口。止盈是否命中、是否先跌破失效位、回踩区间是否真正给到，都可以按原始预测逐条检查。

### 四模式验算口径
- 开盘前：验证当天开盘后至收盘。
- 盘中：只验证预测时刻以后至当日收盘。
- 收盘前大引不成：验证下一交易日。
- 收盘后预测明天：验证下一交易日。

## 强势高位股的回踩买点
V20新增“强势突破回踩”计划。通过追强门槛、或处于明显强势突破状态的股票，不会因为“股价已经很高”自动判坏。
系统会用当时已经存在的：
- ATR14
- MA5 / MA20
- 关键支撑
- 当前价格
生成预先承诺的回踩区间和失效位。
第二天可验证这个回踩价是否合理，而不是涨跌之后再改口。

## V20.1：不用数据库也能自己判卷
最简单流程：

1. 今天选择一个模式 → 点“全自动分析”。
2. 下载页面生成的 `prediction_....csv`。
3. 到验证日重新打开网站。
4. 展开 **“📊 验证昨天/之前的预测 CSV”**。
5. 把昨天的CSV拖进上传框。
6. 点 **“📊 开始判卷”**。

网站会自动抓实际行情，并计算：
- 实际开盘 / 最高 / 最低 / 收盘
- 最大浮盈 / 最大浮亏 / 收盘收益
- 预先写好的回踩买入区间有没有触及
- 第一止盈有没有到
- 强势目标有没有到
- 失效位有没有先被打穿
- 低点以后反弹到收盘有多强
- 自动给出 ✅成功 / 🟡一般 / ❌失败

开盘前预测验证当天；收盘前和收盘后预测验证下一交易日；盘中预测只看预测时刻之后。
Supabase仍然只是可选的“自动保存历史记录”，完全不接也不影响CSV判卷。


## V20.2：推荐时直接显示买入点
第一名推荐不再只显示“推荐谁”，会直接显示：
- 当前价
- 建议买入区间
- 当前动作：`当前就在买入区间 / 等回踩 / 已跌破买入区先别急接`
- 失效位
- 后续第一止盈 / 强势目标

Top5表格也增加“买入动作”列，买入点不会再藏在详细表格或事后验证里。
