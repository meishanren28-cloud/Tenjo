# 强势回踩资金友好大师（72只）V5

这是一个 Streamlit 日股筛选网站。目标不是假装预测明天一定涨，而是：**先排雷 → 判断趋势背景 → 判断回踩质量 → 等重新转强 → 看冲高后的涨幅能不能留住 → 最后在质量相近的候选里优先资金占用更低的股票。**

## V5 新增：涨幅保留率
- 统计近期真正出现过盘中明显拉升（约≥2%）的交易日。
- 看收盘还能保留多少盘中涨幅，而不是只看“盘中曾经冲很高”。
- 冲高后能守住大部分涨幅、收盘重心持续抬高：加分。
- 多次冲高后几乎全部回吐、甚至翻绿：扣分，并记录“冲高失败次数”。
- 这能更好地区分“强票正常回落”和“akippa式每次反弹都留不住”。

## V5 新增：动态止盈
- 一旦是 **A｜强背景+已触发** 的候选，网站同时给出止盈参考。
- 单票诊断可以输入自己的实际买入价/成本价。
- 止盈不是统一写死 +5%，而是综合：
  - ATR14 波动幅度
  - 20日 / 60日前高压力位
  - 实际买入价
  - 当日通常涨停价
- 输出两档：
  - **第一止盈**：更偏落袋，优先考虑近期压力/约0.9 ATR。
  - **强势续抱目标**：如果放量突破且不回落，再看第二档。
- 如果近期多次“冲高全吐”，会额外提示更适合分批兑现。

## 评分结构
- **背景分**：20/60日动量 + MA20斜率 + 过去20日站上MA20比例 + 分段高低点结构 + 涨幅保留质量。
- **触发分**：突破前一日高点、连续回升、上涨伴随合理放量。
- **回踩质量**：靠近支撑、未破MA20/近期平台、从高点适度回撤；下跌时缩量更健康。
- **波动风险**：ATR14、长上影、冲高回落。
- **流动性风险**：20日日均成交额过低会扣分。
- **akippa式弱票硬惩罚**：刷新20日低点、低点持续下移、5/20日走弱、放量不涨。
- **追高惩罚**：单日突然大涨且明显远离MA5时扣分；真正强趋势突破仍可参与，但要看承接。

## 资金友好度
- 按日本现物常见100股一手估算：`一手资金 = 当前价 × 100`。
- 页面可以设置自己能接受的一手资金预算。
- 资金友好度最多只加10分，而且只对 A/B 档健康候选生效。
- **便宜不能救弱票**；只是同质量候选之间的优先因素。

## 评级
- **A｜强背景+已触发**：趋势和买点触发同时较好。
- **B+｜好候选，等转强**：背景不错，但还缺重新转强确认。
- **B｜观察**：结构尚可，但优势一般。
- **C｜中性**：没有明显硬伤，也没有明显优势。
- **回避**：破位、持续创新低等硬伤。

## 日股涨跌停
网站按 JPX 正常制限值幅表，用前一交易日基准价估算正常涨停价/跌停价。连续封板等特殊情形可能扩大制限值幅，应以 JPX 当日公告为准。

## 数据
- 行情：Yahoo Finance / yfinance（免费，可能延迟，不是东证官方逐笔实时）
- 新闻：Google News RSS（免费）
- 股票池：固定72只，保存代码、日文名、中文译名；行情只按代码（如 `6203.T`）抓取。
