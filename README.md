# 强势回踩资金友好大师（72只）V8

这是一个 Streamlit 日股筛选网站。目标不是假装能预测明天，而是：**先排雷 → 判断趋势背景 → 判断回踩质量 → 等重新转强 → 看涨幅能不能留住 → 再结合资金占用和不同交易时段做排序。**

## V8：四种分析模式

### 1. 开盘前
偏重昨收结构、趋势背景、回踩位置与隔夜新闻。今天还没开盘，所以不会把“盘中转强”当作已经发生。

### 2. 盘中
额外抓取免费 5 分钟级别行情，重点看实时转强、当日位置、距日高、量价、冲高回落和追高风险。

### 3. 收盘前｜大引不成
这是专门给“先挂低价限价，若没成交则收盘集合竞价转成市价”的隔夜策略。

重点看：
- 原本趋势背景不能差；
- 尾盘价格最好处在当日相对高位，但不能已经失控加速；
- 最后约30分钟不能明显跳水；
- 最好站在当日 VWAP 上方，但离 VWAP 太远也会扣分；
- 尾盘量能适度增强比突然爆量冲顶更好；
- 当天冲高后的涨幅要能留住；
- 日内涨幅过大、尾盘骗炮、冲高全吐、结构弱都会重罚。

网站会给出 **“大引不成资格”**。如果当天没有股票通过硬门槛，会明确显示：**今天不建议为了下单硬买。**

> 东证现货连续交易到 15:25，之后是 5 分钟 pre-closing，15:30 进行收盘集合竞价。JPX 的 Funari（不成）是限价单若未成交，在收盘集合竞价时转为市价单。实际下单规则以你的券商界面为准。

### 4. 收盘后预测明天
偏重收盘质量、全天涨幅保留、量能、关键位是否守住和新闻催化，用于第二天候选排序。

同一只股票在四个模式得分不同属于设计预期。

## 核心规则
- **原本就强 + 回踩不破关键位 + 再次转强，才考虑买。**
- 连续创新低、收盘重心持续下移的弱票重罚；跌很多不自动抄底。
- 放量不等于强：有量不涨、冲高回落、收盘弱都可能是承接不足。
- 类似 akippa 的弱趋势票，即使突然暴拉也不因为“一根大阳线”追。
- 强趋势突破可以参加，但反对失控加速后的情绪追高。
- 资金少是现实约束：质量相近时优先一手资金更低的股票；便宜绝不救弱票。
- 重视涨幅保留率：冲高后能把涨幅留到收盘加分，反复冲高全吐扣分。

## 动态止盈
网站固定显示止盈计划：
- 参考买入价 / 实际成本价
- **第一止盈**
- **强势续抱目标**
- 对应收益率

止盈结合 ATR14、20/60 日前高压力、买入价和通常涨停价计算，不是统一死板 +5%。非 A 级候选也会显示测算，但会明确标注“仅测算”。

## 资金友好度
- 按日本现物常见 100 股一手估算：`一手资金 = 当前价 × 100`。
- 页面可设置能接受的一手资金预算。
- 资金友好度最多加 10 分，而且只对健康候选生效。

## 日股涨跌停
按 JPX 正常制限值幅表，用前一交易日基准价估算通常涨停价/跌停价。连续封板等特殊情形可能扩大制限值幅，应以 JPX 当日公告为准。

## 股票身份
股票池固定 72 只，同时保存：
- 代码
- 日文正式/常用名
- 中文译名

行情抓取只按代码（如 `6203.T`），名称只用于显示和新闻搜索辅助，减少串票风险。

## 数据
- 行情：Yahoo Finance / yfinance（免费，可能延迟，不是东证官方低延迟行情）
- 新闻：Google News RSS（免费）
- 盘中/尾盘：尽量使用 5 分钟级别免费行情，因此收盘前快速变化时必须再看券商盘口。

## 部署
1. 把 `app.py`、`requirements.txt`、`README.md` 上传到 GitHub 仓库根目录。
2. 在 Streamlit Community Cloud 选择该仓库。
3. Main file path 填 `app.py`。


## V9：盘中短周期结构
- 盘中/收盘前模式增加实际 5 分钟 OHLCV 计算的 5分钟MA20。
- 显示当前价距 5分钟MA20 的偏离、5分钟MA20斜率。
- 检查最近6根5分钟K线的高点/低点是否抬高，形成短周期结构分。
- 数据来自 yfinance/Yahoo Finance 的 5m 数据；抓不到时留空，不用估算值补齐。
- 日线 MA5/MA20 仍保留用于中短期大方向；5分钟结构只负责判断盘中时机。

## V12：健康回调与剩余空间
- 新增“回调质量分”：偏爱强趋势中的 -0.8%~-3.5% 温和回踩，而不是奖励单纯下跌。
- 回调必须配合：支撑未破、MA20结构未坏、5日趋势未崩、下跌量能不过度放大。
- 新增“上方空间/支撑风险比”：仅对健康候选估算回到20日高点的空间，相对当前到关键支撑的距离。
- 回调质量在开盘前、盘中、收盘前大引不成、收盘后四种模式中的权重均提高；追高/深跌仍会被扣分。
- 资金友好仍只是合格候选之间的加分项，不会把便宜弱票救成推荐。


## V13：强势突破追强通道
- 默认仍优先健康回调。
- 对真正强势、接近/突破近期高点、冲高后能留住涨幅的股票，允许进入“追强”候选。
- 追强必须先过风险门槛：近期低点持续下移、冲高保留率差、冲高失败次数过多、20日趋势偏弱、弱势惩罚高，都会直接取消资格。
- 单日加速过猛和 ATR 波动过高会额外扣分。
- 目的：允许追真正的主升/价格发现，同时排除 akippa 式弱票突然暴拉诱多。


## V14：一键回测 + 自动相似结构校准
- 一个按钮完成，不需要手动选样本、设权重或准备数据。
- 自动抓取股票池约2年日线，建立历史技术结构样本。
- 每个历史样本只使用当时已经存在的数据，再观察之后1天/3天结果，避免未来数据泄漏。
- 自动融合：
  - 个股自身历史相似形态；
  - 全72只股票池的相似结构。
- 个股自身历史最多占35%；IPO/短历史股票会自动更多依赖相似股票。
- 概率使用小样本收缩，防止少量案例产生虚假的“90%胜率”。
- 输出：次日上涨概率、3日延续概率、3日假突破风险、相似样本数、次日/3日高低点中位数。
- 历史校准只有限度影响总分；如果历史假突破风险显著偏高，会取消“追强资格”，但不会覆盖实时新闻、盘中结构和硬风险规则。
- 目的：尽量把 4073 类真强势突破与 akippa 类弱势反弹区分开，而不是用“涨得多/跌得多”一刀切。

## V16：夜间PTS自动纳入评分 + KeyError修复
- 不再要求用户自己点夜盘入口；在“收盘后预测明天”和“开盘前”的有效夜盘时段，程序自动读取 Yahoo! Finance Japan 个股页显示的 Japannext J-Market 夜间PTS。
- 自动读取：PTS价格、东证终值比%、PTS成交量、成交额、时间。
- PTS只做辅助校准：根据PTS成交额相对该股20日平均成交额计算可信度；小成交量的异常价格几乎不影响评分。
- “100股/300股夜盘暴涨”会被识别成低可信噪音，不会把弱股硬抬成第一名。
- PTS数据只在当前相关夜盘会话中计分；过期PTS不计分。
- PTS最大影响被限制，不会压过趋势、风险、新闻、盘中结构和回测。
- 修复排名表 `KeyError`：可选模块未生成某列时，页面自动跳过缺失列，不再整站崩溃。
- PTS网页抓取失败时只显示无有效PTS并给0分，不会猜测或补造数据。


## V17：全自动分析
- 前台只保留一个主按钮：`🧠 全自动分析`。
- 用户只需要选择时段，程序自动执行：
  1. 72只股票实时/最近可用行情扫描；
  2. 新闻检索；
  3. 盘中5分钟结构（盘中/收盘前模式）；
  4. 夜间PTS（收盘后/开盘前相关时段）；
  5. 2年历史回测；
  6. 个股自身历史 + 全股票池相似结构校准；
  7. 风险过滤；
  8. 最终推荐与止盈计划。
- 首页优先显示“最终结论”；完整排名和回测细节尽量收进折叠区，减少操作负担。
- 如果没有A级买点，页面会明确显示“当前没有很强买点”，而不是强行制造推荐。
