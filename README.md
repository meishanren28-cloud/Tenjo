# 强势回踩点兵大师（72只）

这是一个 Streamlit 日股筛选网站。核心原则不是预测必涨，而是先用纪律排除弱票，再在相对合格的候选里排序或“点兵”。

## 内置规则
- 原本就强 + 回踩不破关键位 + 再次转强，才考虑。
- 连续创新低、重心下移、放量不涨：重罚。
- 跌很多不自动抄底。
- 突然暴拉、远离 MA5：追高惩罚。
- 强趋势中的小回调（约 -0.5%~-4%）如果仍守 MA20/支撑，会获得“安全回调”加分。
- 新闻只做催化佐证，不覆盖技术面硬伤。
- “大师点兵”只在通过硬规则的前排候选中加权随机，不会把明显弱票随机成推荐。

## 日股涨跌停
网站按 JPX 正常制限值幅表，用前一交易日基准价估算正常涨停价/跌停价。特殊情况下（例如连续无成交封板后）制限值幅可能被临时扩大，应以 JPX 当日公告为准。

## 数据
- 行情：Yahoo Finance / yfinance（免费，可能延迟，不是东证官方逐笔实时）
- 新闻：Google News RSS（免费）

## 部署
1. 把 `app.py`、`requirements.txt`、`README.md` 上传到 GitHub 仓库根目录。
2. 在 Streamlit Community Cloud 选择该仓库。
3. Main file path 填 `app.py`。

## 股票名称与代码
- 股票池固定保存 72 个代码，并另外保存“日文名 / 中文译名”。
- 行情抓取只以代码（如 `6203.T`）为唯一键，名称只用于显示和新闻检索，不会用中文名反查代码。
- 页面中的排行榜、点兵、提问结果、单票诊断都会显示 `代码｜日文名｜中文译名`。
